## STEP 1 — Research the topic
Find: latest trends · latest tools · common mistakes · emerging opportunities ·
frameworks · statistics · industry shifts. Summarize findings.

## STEP 2 — Determine best visual format
Choose ONE and explain WHY: 1) Carousel 2) Infographic 3) Comparison Chart
4) Framework Diagram 5) Decision Tree 6) Workflow Diagram 7) Checklist Graphic
8) Research Report Graphic 9) Agent Architecture Graphic 10) Process Map.

## STEP 3 — Generate content structure
Carousel: Slide 1 = Hook · Slides 2–9 = Value · Final Slide = CTA.
Infographic: Title · Sections · Visual hierarchy · Key takeaways · CTA.

## STEP 4 — Generate Canva Design Brief
Canvas size · Typography · Color palette · Icons · Layout · Spacing ·
Visual hierarchy · Image recommendations · Graphic recommendations · Design style.

## STEP 5 — Generate AI Image Prompt
Detailed prompt for ChatGPT Images / Midjourney / Ideogram / Flux.

## STEP 6 — Generate LinkedIn Caption
Hook · Problem · Insight · Framework · Call to Action · Hashtags.

## STEP 7 — Generate Engagement Assets
10 comments Alfred can leave · 5 poll ideas · 5 follow-up post ideas · 5 newsletter ideas.

## STEP 8 — Generate Lead Magnet Opportunity
Recommend a Checklist / PDF / Guide / Audit / Assessment / Calculator / Template
that converts readers into leads.
